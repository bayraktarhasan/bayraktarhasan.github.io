# Platzhalter für Projektbilder

Da ich keine tatsächlichen Bilder erstellen kann, erstelle bitte eigene Screenshots oder Mockups deiner Projekte und speichere sie hier als:

- `project-1.jpg` (800x600px empfohlen)
- `project-2.jpg` (800x600px empfohlen)
- `project-3.jpg` (800x600px empfohlen)
- `project-4.jpg` (800x600px empfohlen)

## Favicon & Icons

Erstelle folgende Dateien:
- `favicon.svg` (bereits erstellt)
- `favicon.ico` (16x16, 32x32, 48x48)
- `apple-touch-icon.png` (180x180px)
- `icon-192x192.png` (für PWA Manifest)
- `icon-512x512.png` (für PWA Manifest)
- `og-image.jpg` (1200x630px für Social Media Previews)
